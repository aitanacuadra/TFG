Flujo del proceso
1
El cliente envia una peticion HTTP con el archivo CSV o JSON.
2
FastAPI valida la API Key y el archivo, y registra la ejecucion en SQLite.
3
Pandas detecta el formato, genera el perfil de columnas y una muestra de datos.
4
LangChain vectoriza una consulta fija y la lanza contra Qdrant para recuperar contexto normativo.
5
Se construye el prompt completo: system prompt, contexto RAG, perfil y muestra.
6
Ollama ejecuta Gemma 3 con temperatura 0 y devuelve los metadatos en JSON.
7
metadata_service construye el documento JSON-LD conforme a DCAT-AP 3.0.
8
Gemini evalua la calidad del metadato en las 5 dimensiones MQA.
9
Se actualiza SQLite con el estado final y se indexan los metadatos en Qdrant.
10
La API devuelve el documento JSON-LD y la evaluacion MQA al cliente.
